## 概览

Bun 以单个无依赖的可执行文件发布。在 macOS、Linux 和 Windows 上,可以通过安装脚本、包管理器或 Docker 安装。

<Tip>安装完成后,用 `bun --version` 和 `bun --revision` 验证。</Tip>

## 安装

<Tabs>
  <Tab title="macOS 和 Linux">

    <CodeGroup>
      ```bash curl icon="globe"
      curl -fsSL https://bun.com/install | bash
      ```

    </CodeGroup>
    <Note>
      **Linux 用户:** 安装 Bun 需要 `unzip` 包(`sudo apt install unzip`)。建议内核版本 5.6 或更高。Bun 可以运行在低至 3.10 的内核上(RHEL 7),较新的系统调用会优雅降级。用 `uname -r` 检查你的内核版本。
      </Note>

  </Tab>

  <Tab title="Windows">
    <CodeGroup>
      ```powershell PowerShell icon="terminal"
      powershell -c "irm bun.sh/install.ps1|iex"
      ```

    </CodeGroup>
    <Warning>
      Bun 要求 Windows 10 版本 1809 或更高。
    </Warning>


    如需支持与讨论,请加入 [Discord](https://bun.com/discord) 的 **#windows** 频道。

  </Tab>

    <Tab title="包管理器">
    	<CodeGroup>

    	```bash npm icon="npm"
    	npm install -g bun # the last `npm` command you'll ever need
    	```

    	```bash Homebrew icon="/icons/homebrew.svg"
    	brew install oven-sh/bun/bun
    	```

    	```bash Scoop icon="terminal"
    	scoop install bun
    	```

    	</CodeGroup>

    </Tab>

  <Tab title="Docker">
    Bun 提供同时支持 Linux x64 和 arm64 的 Docker 镜像。

    ```bash Docker icon="docker"
    docker pull oven/bun
    docker run --rm --init --ulimit memlock=-1:-1 oven/bun
    ```

    ### 镜像变体

    Bun 还为不同操作系统发布了镜像变体:

    ```bash Docker icon="docker"
    docker pull oven/bun:debian
    docker pull oven/bun:slim
    docker pull oven/bun:distroless
    docker pull oven/bun:alpine
    ```

  </Tab>
</Tabs>

要确认 Bun 安装成功,打开一个新的终端窗口并运行:

```bash terminal icon="terminal"
bun --version
# Output: 1.x.y

# See the precise commit of `oven-sh/bun` that you're using
bun --revision
# Output: 1.x.y+b7982ac13189
```

<Warning>
  如果你已经安装了 Bun,但仍看到 `command not found` 错误,可能需要手动把安装目录(`~/.bun/bin`)加入 `PATH`。
</Warning>

<Accordion title="把 Bun 加入 PATH">
  <Tabs>
    <Tab title="macOS 和 Linux">
      <Steps>
        <Step title="确认你使用的 shell">
        ```bash terminal icon="terminal"
        echo $SHELL
        # /bin/zsh  or /bin/bash or /bin/fish
        ```
        </Step>
        <Step title="打开 shell 配置文件">
          - bash:`~/.bashrc`
          - zsh:`~/.zshrc`
          - fish:`~/.config/fish/config.fish`
        </Step>
        
        <Step title="把 Bun 目录加入 PATH">
          在配置文件中加入以下行:
          ```bash terminal icon="terminal"
          export BUN_INSTALL="$HOME/.bun"
          export PATH="$BUN_INSTALL/bin:$PATH"
          ```
        </Step>
        
        <Step title="重新加载 shell 配置">
          ```bash terminal icon="terminal"
          source ~/.bashrc  # or ~/.zshrc
          ```
        </Step>
      </Steps>
    </Tab>
    <Tab title="Windows">
      <Steps>
        <Step title="确认 bun 二进制已正确安装">
        ```bash terminal icon="terminal"
        & "$env:USERPROFILE\.bun\bin\bun" --version
        ```

        如果该命令能成功运行,但 `bun --version` 无法识别,说明 bun 不在系统 PATH 中。修复方法:打开 PowerShell 终端并运行以下命令:

        ```bash terminal icon="terminal"
        [System.Environment]::SetEnvironmentVariable(
          "Path",
          [System.Environment]::GetEnvironmentVariable("Path", "User") + ";$env:USERPROFILE\.bun\bin",
          [System.EnvironmentVariableTarget]::User
        )
        ```

        </Step>
        <Step title="重启终端">
           重启终端并用 `bun --version` 测试。

          ```bash terminal icon="terminal"
          bun --version
          ```
        </Step>
      </Steps>
    </Tab>

  </Tabs>
</Accordion>

## 升级

安装后,二进制文件可以自我升级:

```bash terminal icon="terminal"
bun upgrade
```

<Tip>
**Homebrew 用户** <br />
为避免与 Homebrew 冲突,请改用 `brew upgrade bun`。

**Scoop 用户** <br />
为避免与 Scoop 冲突,请改用 `scoop update bun`。

</Tip>

## Canary 构建

[-> 查看 canary 构建](https://github.com/oven-sh/bun/releases/tag/canary)

每次向 main 分支提交,Bun 都会自动发布一个(未测试的)canary 构建。要升级到最新 canary 构建:

```bash terminal icon="terminal"
# Upgrade to latest canary
bun upgrade --canary

# Switch back to stable
bun upgrade --stable
```

可以使用 canary 构建在正式版发布前测试新特性和缺陷修复。为帮助 Bun 团队更快修复缺陷,canary 构建会自动上传崩溃报告。

## 安装旧版本

由于 Bun 是单个二进制文件,重新运行指定版本的安装脚本即可安装旧版本。

<Tabs>
  <Tab title="Linux 和 macOS">
    要安装特定版本,把 git tag 传给安装脚本:

    ```bash terminal icon="terminal"
    curl -fsSL https://bun.com/install | bash -s "bun-v1.3.3"
    ```

  </Tab>
  <Tab title="Windows">
    在 Windows 上,把版本号传给 PowerShell 安装脚本:

    ```powershell PowerShell icon="windows"
    iex "& {$(irm https://bun.com/install.ps1)} -Version 1.3.3"
    ```

  </Tab>
</Tabs>

### Musl 二进制

适用于不带 `glibc` 的发行版(Alpine Linux、Void Linux):

- [Linux x64 musl](https://github.com/oven-sh/bun/releases/latest/download/bun-linux-x64-musl.zip)
- [Linux ARM64 musl](https://github.com/oven-sh/bun/releases/latest/download/bun-linux-aarch64-musl.zip)

<Note>
  Bun 的 glibc 二进制要求 glibc 2.17 或更高。如果遇到 `bun:
  /lib/x86_64-linux-gnu/libc.so.6: version GLIBC_... not found` 这类错误,请改用 musl 二进制。Bun 的安装脚本会自动为你的系统选择正确的二进制。
</Note>

## CPU 要求

Bun 每个平台只发布一个 x64 二进制。它以 Nehalem 微架构(SSE4.2)为目标,并在运行时根据 CPU 支持情况选择 AVX2/AVX-512 代码路径,因此无需挑选单独的 "baseline" 下载。

| 平台 | Intel 要求                | AMD 要求           |
| ---- | ------------------------- | ------------------ |
| x64  | Nehalem(第一代 Core)或更新 | Bulldozer 或更新 |

<Note>
  Bun 不支持不带 SSE4.2 扩展的 x64 CPU。Bun 要求 macOS 13.0 或更高。`-baseline` release 资产和 `@oven/bun-*-x64-baseline` npm 包仅作为单一 x64 二进制的别名保留,以兼容旧的安装脚本。
</Note>

## 卸载

从系统中移除 Bun:

<Tabs>
	<Tab title="macOS 和 Linux">
  ```bash terminal icon="terminal"
  rm -rf ~/.bun
  ```
  </Tab>

    <Tab title="Windows">
    	```powershell PowerShell icon="windows"
    powershell -c ~\.bun\uninstall.ps1
    ```
    </Tab>

    <Tab title="包管理器">
    	<CodeGroup>
    		```bash npm icon="npm"
      npm uninstall -g bun
      ```
      ```bash Homebrew icon="/icons/homebrew.svg"
      brew uninstall bun
      ```
      ```bash Scoop icon="terminal"
      scoop uninstall bun
      ```
    	</CodeGroup>
    </Tab>

</Tabs>
