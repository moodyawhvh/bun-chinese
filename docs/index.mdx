## 包含哪些内容

- 运行时:以近乎零开销执行 JavaScript/TypeScript 文件和 package 脚本。

## Bun 是什么?

Bun 是面向 JavaScript 和 TypeScript 应用的一体化工具集,以单个名为 `bun` 的可执行文件发布。

其核心是 _Bun 运行时_,一个旨在**直接替换 Node.js** 的高速 JavaScript 运行时。它使用 Rust 编写、由 JavaScriptCore 驱动,启动时间和内存占用都更低。

```bash terminal icon="terminal"
bun run index.tsx  # TS and JSX supported by default
```

`bun` 命令行工具还实现了测试运行器、脚本运行器和与 Node.js 兼容的包管理器。这三者都比现有工具快得多,并且几乎无需改动就能用在现有 Node.js 项目中。

```bash terminal icon="terminal"
bun run start                 # run the `start` script
bun install <pkg>             # install a package
bun build ./index.tsx         # bundle a project for browsers
bun test                      # run tests
bunx cowsay 'Hello, world!'   # execute a package
```

## 什么是运行时?

JavaScript(更正式的称呼是 ECMAScript)只是一份编程语言的_规范_。任何人都可以编写一个 JavaScript _引擎_,接收合法的 JavaScript 程序并执行它。当今最流行的两个引擎是 V8(Google 开发)和 JavaScriptCore(Apple 开发),二者都是开源的。

但大多数 JavaScript 程序并非在真空中运行,它们需要访问外部世界才能完成有用的任务。这正是_运行时_的用武之地:运行时实现额外的 API,并提供给它所执行的 JavaScript 程序。

### 浏览器

浏览器自带 JavaScript 运行时,实现了一组 Web 专属 API,暴露在全局 `window` 对象上。浏览器执行的任何 JavaScript 代码都可以使用这些 API 为当前网页添加交互或动态行为。

### Node.js

Node.js 是面向非浏览器环境(如服务器)的 JavaScript 运行时。Node.js 执行的 JavaScript 程序除了能使用处理操作系统级任务(如读写文件 `node:fs`、网络 `node:net`、`node:http`)的内置模块外,还可以访问一组 Node.js 专属的[全局对象](https://nodejs.org/api/globals.html),如 `Buffer`、`process`、`__dirname`。Node.js 还实现了一套基于 CommonJS 的模块系统和解析算法,早于 JavaScript 原生模块系统出现。

Bun 的定位是更快、更精简、更现代的 Node.js 替代品。

## 设计目标

Bun 从零开始设计,充分照顾当今的 JavaScript 生态。

- **速度**。Bun 进程启动速度[比 Node.js 快 4 倍](https://twitter.com/jarredsumner/status/1499225725492076544)。
- **TypeScript 和 JSX 支持**。可以直接执行 `.jsx`、`.ts`、`.tsx` 文件;Bun 的转译器会在执行前把它们转换成原生 JavaScript。
- **ESM 与 CommonJS 兼容**。世界正在转向 ES 模块(ESM),但 npm 上仍有数百万个包依赖 CommonJS。Bun 推荐 ES 模块,同时支持 CommonJS。
- **Web 标准 API**。Bun 实现了 `fetch`、`WebSocket`、`ReadableStream` 等标准 Web API。Bun 由 Apple 为 Safari 开发的 JavaScriptCore 引擎驱动,因此 [`Headers`](https://developer.mozilla.org/en-US/docs/Web/API/Headers)、[`URL`](https://developer.mozilla.org/en-US/docs/Web/API/URL) 等 API 直接使用 [Safari 的实现](https://github.com/oven-sh/bun/blob/HEAD/src/jsc/bindings/webcore/JSFetchHeaders.cpp)。
- **Node.js 兼容**。除了支持 Node 风格的模块解析,Bun 还力求与 Node.js 内置全局对象(`process`、`Buffer`)和模块(`path`、`fs`、`http`)完全兼容。_这项工作仍在进行中。_ 当前进展见 [Node.js 兼容性](/runtime/nodejs-compat)。

Bun 不只是一个运行时。长期目标是打造一套完整的基础设施工具集,用于构建 JavaScript/TypeScript 应用:包管理器、转译器、打包器、脚本运行器和测试运行器。
