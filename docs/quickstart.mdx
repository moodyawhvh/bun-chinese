## 概览

用 `Bun.serve` 构建一个最小 HTTP 服务器,在本地运行,然后通过安装一个包来扩展它。

<Info>前置条件:已安装 Bun 并加入 `PATH`。安装配置见[安装文档](/installation)。</Info>

---

<Steps>
  <Step title="第 1 步">

    用 `bun init` 初始化一个新项目。

    ```bash terminal icon="terminal"
    bun init my-app
    ```

    `bun init` 会提示你选择模板:`Blank`、`React` 或 `Library`。本指南选择 `Blank`。

    ```bash terminal icon="terminal"
    bun init my-app
    ```
    ```txt
    ✓ Select a project template: Blank

    + .gitignore
    + CLAUDE.md
    + .cursor/rules/use-bun-instead-of-node-vite-npm-pnpm.mdc -> CLAUDE.md
    + index.ts
    + tsconfig.json (for editor autocomplete)
    + README.md
    ```

    新生成的 `my-app` 目录包含一个基础的 Bun 应用。

  </Step>
  <Step title="第 2 步">

    用 `bun run` 运行 `index.ts`。

    ```bash terminal icon="terminal"
    cd my-app
    bun run index.ts
    ```
    ```txt
    Hello via Bun!
    ```

  </Step>
  <Step title="第 3 步">

    把 `index.ts` 的内容替换为以下代码:

    ```ts index.ts icon="/icons/typescript.svg"
    const server = Bun.serve({
      port: 3000,
      routes: {
        "/": () => new Response('Bun!'),
      }
    });

    console.log(`Listening on ${server.url}`);
    ```

    再次运行 `index.ts`。

    ```bash terminal icon="terminal"
    bun run index.ts
    ```
    ```txt
    Listening on http://localhost:3000/
    ```

    访问 [`http://localhost:3000`](http://localhost:3000) 测试服务器,你应该会看到一个显示 `"Bun!"` 的页面。

    <Accordion title="在 Bun 上看到 TypeScript 报错?">

      `bun init` 会安装 Bun 的 TypeScript 类型声明并配置好 `tsconfig.json`。如果你是在现有项目中试用 Bun,可能会在 `Bun` 全局对象上看到类型错误。

      要解决,先把 `@types/bun` 安装为开发依赖。

      ```bash terminal icon="terminal"
      bun add -d @types/bun
      ```

      然后在 `tsconfig.json` 的 `compilerOptions` 中加入以下内容:

      ```json tsconfig.json icon="file-json"
      {
        "compilerOptions": {
          "lib": ["ESNext"],
          "target": "ESNext",
          "module": "Preserve",
          "moduleDetection": "force",
          "moduleResolution": "bundler",
          "allowImportingTsExtensions": true,
          "verbatimModuleSyntax": true,
          "noEmit": true
        }
      }
      ```

    </Accordion>

  </Step>
  <Step title="第 4 步">

    安装 `figlet` 包及其类型声明。Figlet 是一个把字符串转换成 ASCII 艺术字的工具。

    ```bash terminal icon="terminal"
    bun add figlet
    bun add -d @types/figlet # TypeScript users only
    ```

    更新 `index.ts`,在 `routes` 中使用 `figlet`。

    ```ts index.ts icon="/icons/typescript.svg"
    import figlet from 'figlet'; // [!code ++]

    const server = Bun.serve({
      port: 3000,
      routes: {
        "/": () => new Response('Bun!'),
        "/figlet": () => { // [!code ++]
          const body = figlet.textSync('Bun!'); // [!code ++]
          return new Response(body); // [!code ++]
        } // [!code ++]
      }
    });

    console.log(`Listening on ${server.url}`);
    ```

    再次运行 `index.ts`。

    ```bash terminal icon="terminal"
    bun run index.ts
    ```
    ```txt
    Listening on http://localhost:3000/
    ```

    访问 [`http://localhost:3000/figlet`](http://localhost:3000/figlet) 测试服务器,你应该会看到以 ASCII 艺术字呈现的 `"Bun!"`。

    ```txt
    ____              _
    | __ ) _   _ _ __ | |
    |  _ \| | | | '_ \| |
    | |_) | |_| | | | |_|
    |____/ \__,_|_| |_(_)
    ```

  </Step>
  <Step title="第 5 步">

    现在加入一些 HTML。新建一个 `index.html` 文件:

    ```html index.html icon="file-code"
    <!DOCTYPE html>
    <html lang="en">
      <head>
        <meta charset="UTF-8">
        <meta name="viewport" content="width=device-width, initial-scale=1.0">
        <title>Bun</title>
      </head>
      <body>
        <h1>Bun!</h1>
      </body>
    </html>
    ```

    然后在 `index.ts` 中导入该文件,并由根路由 `/` 提供服务。

    ```ts index.ts icon="/icons/typescript.svg"
    import figlet from 'figlet';
    import index from './index.html'; // [!code ++]

    const server = Bun.serve({
      port: 3000,
      routes: {
        "/": index, // [!code ++]
        "/figlet": () => {
          const body = figlet.textSync('Bun!');
          return new Response(body);
        }
      }
    });

    console.log(`Listening on ${server.url}`);
    ```

    再次运行 `index.ts`。

    ```bash terminal icon="terminal"
    bun run index.ts
    ```
    ```txt
    Listening on http://localhost:3000/
    ```

    访问 [`http://localhost:3000`](http://localhost:3000) 测试服务器,你应该会看到这个静态 HTML 页面。

  </Step>

</Steps>

你已经用 Bun 构建了一个 HTTP 服务器,并安装了一个包。

## 运行脚本

Bun 也能执行 `package.json` 中的 `"scripts"`。添加如下脚本:

{/* prettier-ignore */}
```json package.json icon="file-json"
{
  "name": "my-app",
  "module": "index.ts",
  "type": "module",
  "private": true,
  "scripts": { // [!code ++]
    "start": "bun run index.ts" // [!code ++]
  }, // [!code ++]
  "devDependencies": {
    "@types/bun": "latest"
  },
  "peerDependencies": {
    "typescript": "^7"
  }
}
```

然后用 `bun run start` 运行。

```bash terminal icon="terminal"
bun run start
```

```txt
Listening on http://localhost:3000/
```

<Note>⚡️ **性能** — `bun run` 比 `npm run` 快约 28 倍(开销 6ms 对 170ms)。</Note>
