要获得 Bun 内置 API 的 TypeScript 类型定义,请安装 `@types/bun`。

```zsh terminal icon="terminal"
bun add -d @types/bun # dev dependency
```

此后即可在 TypeScript 文件中引用 `Bun` 全局对象,编辑器不会再报错。

## 推荐的 `compilerOptions`

Bun 支持顶层 await、JSX 以及带 `.ts` 扩展名的导入,这些是 TypeScript 默认不允许的。在 Bun 项目中使用以下 `compilerOptions`,TypeScript 就不会对这些特性报警。

```json tsconfig.json icon="file-json"
{
  "compilerOptions": {
    // Environment setup & latest features
    "lib": ["ESNext"],
    "target": "ESNext",
    "module": "Preserve",
    "moduleDetection": "force",
    "jsx": "react-jsx",
    "allowJs": true,
    "types": ["bun"],

    // Bundler mode
    "moduleResolution": "bundler",
    "allowImportingTsExtensions": true,
    "verbatimModuleSyntax": true,
    "noEmit": true,

    // Best practices
    "strict": true,
    "skipLibCheck": true,
    "noFallthroughCasesInSwitch": true,
    "noUncheckedIndexedAccess": true,
    "noImplicitOverride": true,

    // Some stricter flags (disabled by default)
    "noUnusedLocals": false,
    "noUnusedParameters": false,
    "noPropertyAccessFromIndexSignature": false
  }
}
```

在新目录中运行 `bun init` 会自动生成这份 `tsconfig.json`。

```sh terminal icon="terminal"
bun init
```

## TypeScript 6 和 7

如果你使用 TypeScript 6.0 或更高版本,还需要在 `compilerOptions` 中加入 `"types": ["bun"]`。详见 [TypeScript 6 和 7](/typescript-6)。
