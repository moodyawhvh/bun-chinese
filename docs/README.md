## 参与贡献

欢迎贡献。可以提交 issue 或发起 pull request。

在编写或修改页面之前,请先阅读[文风指南](https://bun.com/docs/project/contributing#voice)(源文件:`project/contributing.mdx`):使用短句、主动语态、现在时态、第二人称,避免使用 "easy"、"simple"、"just" 这类词。
